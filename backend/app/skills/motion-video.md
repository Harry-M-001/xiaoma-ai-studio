## 何时使用

用户要片头、条形图、编号教程、促销卡、倒计时，或明确要求用代码渲染时，使用 `render_motion_video`。如果需求是人物表演、实拍风格或复杂物体运动，使用画布视频节点。用户只要方案时，给出分幕方案并等待下一条指令。

## 从分幕到成片

1. 先列出必需的文字、数字、画幅、总时长与分幕约束。颜色和动效由你决定。按用户原文制作，优先省略无来源的副标题。促销场景尤其不要新增限时、库存、折扣、适用范围等事实；教程额外参数也要有用户依据。没有指定画幅或时长时可用 16:9 和每幕 3 秒。
2. 先选布局，再写分幕。每条片有 1–6 幕。每幕有标题（最多 40 字）、可选副标题（最多 70 字）和整数秒（1–6）。背景与强调色用 `#RRGGBB`。动效可选 `rise`（淡入上移）、`fade`（淡入）和 `none`（静态）。

   | 布局 | 适用场景和要求 |
   | --- | --- |
   | `title` | 片头、章节卡。 |
   | `bars` | 比例条形图。传 `bars: [{"label":"Q1","value":24},{"label":"Q2","value":42}]`。在同一幕传入 2–4 组原始值，条长由渲染器自动计算。 |
   | `step` | 教程。每幕传独立的 `step` 整数，标题保留步骤内容。 |
   | `offer` | 促销。传字符串 `price` 和 `cta`，标题写产品。渲染器分别排价格和行动按钮。 |
   | `countdown` | 真正的逐秒倒计时。在一幕设置期望的 `seconds`，例如 5 秒从 5 数到 1，保留标题。 |

   用户要求同一幕时，不拆成数个标题卡。用户给的数值、币种和文案，按原样放在各自字段。
3. 直接调用 `render_motion_video`。输入示例：

   ```json
   {
     "name": "雨夜便利店",
     "ratio": "16:9",
     "scenes": [
       {"title": "雨夜便利店", "subtitle": "一盏灯，一场雨", "seconds": 2},
       {"title": "橘猫的夜班", "seconds": 2, "motion": "fade"}
     ]
   }
   ```

4. 工具成功后，核对返回的实际画幅、时长、编码与分幕字段，再用资产 ID 和播放地址交付。该工具已校验媒体规格，直接使用本次结果。只有用户要的证据尚未返回时才再查资产。参数错误时修正对应分幕。缺少 FFmpeg、FFprobe 或 drawtext 时，说明本机依赖。

本工具把分幕作为数据交给工坊的固定渲染器。标题文字按原样处理。支持横屏、竖屏和方形，输出 30 fps H.264 MP4，无音轨。
