# 长篇一致性检查

## 一致性靠什么保证

- **资产表**（`assetSheet`）是唯一事实源：人物 / 场景 / 道具各有中文名与英文视觉描述；
- 出图/出片时，节点会**按资产名自动注入参考图**；所以名字写错 = 参考图注入不到 = 人物走形；
- 代码里没有 seed，**风格靠风格卡与提示词词汇**，不靠随机种子。

## 检查步骤

1. `get_canvas` 读全图，找到资产表与分镜节点；
2. 比对：分镜里出现的**人物名**是否都能在资产表里找到；
3. 找出「同一人物不同称呼」（如「沈青梧 / 青梧 / 沈师姐」）——这是一种真实的不一致；
4. `lint_canvas` 看镜头层问题；
5. 把问题按「哪个节点 / 哪一句 / 建议怎么改」列给用户，不要一次列二十条。

## 改的时候

- 统一称呼优先改**分镜表文本**（`update_node` 的 prompt），不要改资产表的中文名——资产名一改，历史产物就对不上了；
- 用户没确认前不要重建节点。
