# 三条有声程序化短片的 Agent 对照

同题测试包括水上乐园宣传、中性笔产品宣传、乡村小镇晨景。每条要求横屏、10 秒，动作明确并有配乐或环境音。直接版由代码制作。工坊版使用项目已配置的 DeepSeek V4.1 Flash 开启思考模式，在隔离库里选择技能并调用本机渲染。测试未接入任何图像或视频生成服务。

| 主题 | 直接版的编排 | Agent 升级前 | Agent 升级后 |
| --- | --- | --- | --- |
| 水上乐园 | 沿曲线移动游客，在入水位置触发水花与音效。结尾切宣传语。 | 用五张 2 秒文字卡叙述动作，检查本机引擎后交付无声片。3 次调用。 | 选择 `water_park`，填写宣传标题与结尾。画面有滑行、水花，音轨有配乐和动作音效。2 次。 |
| 中性笔 | 先旋转展示笔身，随后逐帧对齐笔尖与墨迹的生长位置。 | 用三张文字卡描述特写与书写，另查引擎与资产。无声。4 次。 | 选择 `gel_pen`，编写开场和结尾。渲染器生成产品动效、书写声与轻音乐。2 次。 |
| 乡村小镇 | 多层山脊视差、移动薄雾、村舍与河面反光，合成鸟鸣、水声和舒缓配乐。 | 用四幕标题和配色示意晨景。实际无村景、无声音。3 次。 | 选择 `rural_town`，自拟晨景标题和结尾。输出有场景动效和环境音。2 次。 |

旧版的五种排版能力适合文字动效。当合成场景和声音超出工具支持时，Agent 会转成卡片，并在回复里说明差异。升级增加了固定有声场景能力，模型负责从简报选择模板、编排标题和交付，渲染器负责逐帧动画与混音。三个场景共从 10 次工具调用降到 6 次。复测中每题均只使用 `load_skill → render_showcase_video`。

## 交付与验收

- 新技能「本地有声场景短片」可在 Agent 工具区选择。支持已有三种插画场景，开场与结尾文案可替换。
- 成片沿用资产库与 Agent 时间线。工具返回实际画幅、时长、编码、音频格式、声道数和音轨元素。三条 Agent 成片由 FFprobe 验证均为 10.00 秒、1280×720、24 fps、H.264、AAC 双声道，并用音量检测确认音轨有实际信号。
- 当前模板提供合成音乐和音效，固定为 10 秒横屏，素材风格为插画。任务需要新题材、真人旁白或任意画幅时，应重新评估所需的制作工具。
- 旧版 Agent、直接版、升级后 Agent 共九条样片汇总于 `dist/complex-motion/agent-comparison.zip`。对应工具记录位于 `agent-baseline` 和 `agent-final` 下。

## 复现

安装后端依赖并准备本机 FFmpeg 和 FFprobe。命令使用当前仓库里已配置的 DeepSeek 文本模型。

```powershell
python backend/tools/agent_motion_comparison.py agent dist/complex-motion/agent-final --showcase
```
