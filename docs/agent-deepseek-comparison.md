# DeepSeek V4.1 Flash 工坊 Agent 对照实测

## 环境与任务

使用仓库现有的 DeepSeek V4.1 Flash 文本配置，开启思考模式。测试实例只导入选中的文本配置和对应的本地加密材料，不读取工作台的项目与素材。Seedream 5.5 和 Seedance 2.0 均由本地模拟服务处理。任务是根据同一份「雨夜便利店」需求生成一张参考图和一条 4 秒、16:9 的视频，视频节点请求 720p。

## 执行方式对照

| 执行者 | 可观察到的策略 | 结果 |
| --- | --- | --- |
| Codex 直接调用画布 API | 给已知的两节点拓扑填参数和固定模型，保存画布、执行，按运行 ID 查摘要并核对节点状态。 | 1 图、1 条 4 秒模拟视频，0 个失败任务。提交运行后约 12.6 秒。 |
| 工坊 Agent，升级前 | 读取画布、查模型、生成和应用草稿、回查参数、预估、执行、等待。等待后再分别查画布状态、资产列表和一条任务以收集交付证据。 | 11 次 Agent 工具调用，0 个失败工具，约 50.3 秒。 |
| 工坊 Agent，升级后 | 保留布局、模型与参数核对，执行后把运行 ID 交给等待工具，从返回的资产 ID、URL、时长和实际尺寸直接交付。 | 8 次 Agent 工具调用，0 个失败工具，约 35.7 秒。 |

以上是各一次实测。直接调用的计时从提交运行开始，Agent 计时含模型编排。工具调用数衡量 Agent 自身的决策路径。两条路径的最终媒体生成请求均为一次模拟出图和一次模拟视频提交。模型模拟器按自身规格落盘，因此视频文件实测 480×270，画布发出的请求仍为 720p。报告以实际尺寸区分请求和产物。

## 已实现的改进

- 等待工具支持按项目 ID 和运行 ID 取证，返回成功、失败或取消信息及本次资产。大量结果保留总数并优先展示失败和取消任务。
- 内置「成片验收与局部修复」技能。指导 Agent 按本次运行核验交付，保护已成功的产物。
- 内置「本地程序化视频」技能。Agent 按需加载，用户也可在工具区点击「使用」。采用结构化分幕，支持横屏、竖屏、方形，最多 6 幕、每幕 1–6 秒，输出无音轨的 H.264 MP4。适合片头、章节卡和动态文字。 [Remotion 参数化合成](https://www.remotion.dev/docs/parameterized-rendering) · [FFmpeg drawtext](https://ffmpeg.org/ffmpeg-filters.html#drawtext)
- 真实 DeepSeek 测试中，Agent 先加载技能，再调用本地渲染工具。FFprobe 验证成片为 1280×720、30 fps、4 秒 H.264，两幕中文标题可读。整个渲染场景只调用 DeepSeek 文本和本机 FFmpeg。

## 复现

从仓库根运行。测试解释器需具备后端依赖与 Pillow，并能使用本机 FFmpeg 和 FFprobe。模拟服务使用 8790，隔离工坊使用 8791。

```powershell
python backend/tools/agent_comparison.py --render --output dist/agent-comparison.json --video-output dist/agent-motion-demo.mp4
```

其中 `--agent-only` 可跳过直接画布组。脚本将新任务写入独立临时目录，正常退出后清理。文本请求使用用户已接入的 DeepSeek 配置，可能产生文本模型费用。
